把下面 6 步做完，密码页就自动每天更新了（约 5 分钟，只需做一次）

【1】打开 https://github.com/new
      仓库名：gfx-daily-password
      可见性：Public（朋友不需要登录就能看）
      勾选 Add a README file → Create repository

【2】进入仓库 → Add file → Upload files
      把本压缩包里的这些拖进去（保持目录结构）：
        README.md
        password.md
        scripts/daily.py
        .github/workflows/daily-password.yml
      （Windows 资源管理器里默认看不到 .github 文件夹，可以先解压到桌面再拖）
      然后点 Commit changes

【3】仓库 → Settings → Secrets and variables → Actions
      → New repository secret
         Name : GFX_SECRET
         Secret: GfxDaily-2026-7A1C93B5E2
      → Add secret

【4】仓库 → Actions 标签
      左侧选「每日更新密码」→ 右侧 Run workflow → Run workflow

【5】等 30 秒刷新，仓库根目录会出现/更新 password.md
      打开它，里面第一行就是今天密码

【6】把这个地址发给朋友（把 <你> 换成你的用户名）：
      https://github.com/<你>/gfx-daily-password/blob/main/password.md

之后每天北京时间 00:00 自动更新，你不用管。

想手动改密码规则：改 scripts/daily.py 里的 SECRET，同时改解锁器源码里的
GfxDailyPassword.Secret 并重新编译，再更新仓库里的 GFX_SECRET。
